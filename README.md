# kotoba-desktop

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
![Platform: Windows 11](https://img.shields.io/badge/Platform-Windows%2011-0078d4.svg)

Windowsの標準音声入力機能の精度が低いため、ローカルのみで動く音声入力ツールを作成しました

ショートカットキー（最初は **Ctrl+H**）を押して話し、もう一度押すと、話した内容が文字になってカーソルの位置に入ります。メモ帳、ブラウザ、Slack、VS Code / Cursor、ターミナルなど、文字を入力できる場所ならどこでも使えます。

## 特長

- **パソコンの中だけで動きます。** 音声認識は手元の GPU で行い、音声や文字をインターネットに送りません（ネットワークを使うのは、最初に音声認識のモデルをダウンロードするときだけです）。
- **高い精度の音声認識です。** OpenAI の [Whisper large-v3-turbo](https://huggingface.co/openai/whisper-large-v3-turbo) を使います。設定ファイルで、日本語向けに作られた [kotoba-whisper](https://huggingface.co/kotoba-tech/kotoba-whisper-v2.0-faster) に切り替えることもできます。
- **文字が崩れません。** 1 文字ずつキーを打つのではなく、まとめて 1 回で貼り付けるので、ターミナルなどでも文字の順番が入れ替わったり、勝手に変換されたりしません。貼り付けに使ったクリップボードは、元の内容に戻します。
- **Enter は押しません。** 入力するだけなので、チャットで勝手に送信されたり、ターミナルでコマンドが実行されたりしません。

## 必要なもの

| 必要なもの | 確かめ方 |
| --- | --- |
| Windows 11 | 「設定」→「システム」→「バージョン情報」 |
| NVIDIA の GPU（ビデオメモリ 4 GB 以上） | タスクマネージャー（Ctrl+Shift+Esc）の「パフォーマンス」タブに「GPU」があり、名前に「NVIDIA」と出ていれば OK |
| マイク | パソコン内蔵のマイクや Web カメラのマイクでも使えます |
| 空き容量 約 3 GB | アプリが使う部品と、音声認識のモデルの分です |

NVIDIA のドライバは、できるだけ新しいものにしておいてください（[ドライバのダウンロード](https://www.nvidia.com/ja-jp/drivers/)）。AMD や Intel の GPU、GPU が無いパソコンでは今のところ使えません。

## インストール

1. [Releases](https://github.com/AkiraMatsumoto-github/kotoba-desktop/releases/latest) のページを開き、「Assets」にある **`kotoba-desktop-<バージョン>-setup.exe`** をダウンロードします。
2. ダウンロードしたファイルを開き、画面の案内に従ってインストールします。管理者の権限は要りません。
   - 「Windows によって PC が保護されました」と出たときは、「**詳細情報**」→「**実行**」を押してください（個人で作っているアプリで、電子署名をしていないために出ます）。
   - 「Windows にサインインしたときに起動する」にチェックを入れておくと、パソコンを起動するたびに自動で起動します。
3. インストールが終わると、アプリが起動します。

**初回の起動時だけ**、音声認識のモデル（約 1.6 GB）を自動でダウンロードします。回線によっては数分〜十数分かかり、終わるまでトレイのアイコンは灰色のままです。

新しいバージョンが出たときは、同じように新しい `setup.exe` を実行すれば上書きされます（設定はそのまま残ります）。

## 使い方

### 起動する

スタートメニューから「**kotoba-desktop**」を選びます。

画面右下のタスクトレイ（時計の近く）に、マイクのアイコンが出ます。アイコンが見当たらないときは、「^」を押すと隠れたアイコンの中にあります。

| アイコンの色 | 状態 |
| --- | --- |
| 灰色 | 準備中（起動してから 10 秒ほど）。この間はまだ使えません |
| 青 | 使える状態 |
| 赤 | 録音中 |

パソコンを起動するたびに自動で起動させたいときは、下の「[パソコンの起動時に自動で起動する](#パソコンの起動時に自動で起動する)」を参照してください。

### 話して入力する

1. 文字を入力したい場所（メモ帳、ブラウザの入力欄など）をクリックして、カーソルを置きます。
2. **Ctrl+H** を押します。画面の下に小さなパネルが出ます。
3. パネルに「**聞き取り中…**」と出たら話します。
4. 話し終わったら、もう一度 **Ctrl+H** を押します。
5. 1 秒もかからずに、話した内容がカーソルの位置に入ります。

パネルのマイクボタンをクリックしても、開始・終了できます。クリックしても、入力先のカーソルはそのままです。録音中はパネルに声の波形が出ます。録音をやめたいときは、パネル右端の「×」を押すと、何も入力せずに閉じます。

うまく入力できなかったときは、トレイのアイコンを右クリック →「**履歴**」から、直近 10 件の結果を入力し直せます。

### 終了する

トレイのアイコンを右クリック →「**終了**」を選びます。

## 設定

トレイのアイコンを右クリック →「**設定…**」で、次の項目を変えられます。

| 項目 | 内容 |
| --- | --- |
| 録音の開始 / 終了 | ショートカットキー。入力欄をクリックしてから、使いたいキーの組み合わせを押して選びます |
| マイク | 使うマイク。複数のマイクがつながっているときに選びます |
| マイクを開いたままにする | 話し始めの言葉が抜けるときにオンにします。オンにすると、タスクバーにマイク使用中のマークが出続けます |
| 句読点 | 「、。」を付けたまま入力するか、取り除くか |
| ウィジェットを常に表示する | オンにすると、パネルが出たままになります（マウスだけで使いたいとき） |
| 置換辞書 | よく間違える言葉の直し方を登録します（例: 「クロードコード」→「Claude Code」） |

> [!IMPORTANT]
> ショートカットキーに選んだキーは、他のアプリでは使えなくなります。最初の Ctrl+H のままだと、VS Code / Cursor の「置換」やブラウザの「履歴」などが使えません。困るときは、設定で別のキーに変えてください。Windows 標準の音声入力が使っている Win+H は選べませんが、Win+Alt+H のような組み合わせは選べます。

## パソコンの起動時に自動で起動する

インストールのときに「Windows にサインインしたときに起動する」を選んでいれば、設定済みです。後から変えたいときは、`setup.exe` をもう一度実行して選び直すか、「設定」→「アプリ」→「スタートアップ」で kotoba-desktop をオン / オフしてください。

## 困ったとき

<details>
<summary>トレイにアイコンが出ない / 起動しない</summary>

- すでに起動していると「既に起動しています」と表示されます。トレイの「^」の中も探してください。
- 起動に失敗したときは、ログ（`%APPDATA%\kotoba-desktop\kotoba-desktop.log`）に理由が書かれています。エクスプローラーのアドレスバーにこのパスを貼り付けると開けます。
- 「モデルを読み込めません」と出るときは、インターネットにつながっていることを確かめて、アプリを起動し直してください（モデルのダウンロードをやり直します）。

</details>

<details>
<summary>Ctrl+H を押しても反応しない</summary>

- アイコンが灰色の間は準備中です。青になるまで待ってください。
- 他のアプリがすでに Ctrl+H を使っていると、起動時に「登録できません」と通知が出ます。設定で別のキーに変えてください。

</details>

<details>
<summary>文字が入力されない</summary>

- 「管理者として実行」しているアプリには、Windows の仕組み上、入力できません。そのときは結果がクリップボードに入るので、Ctrl+V で貼り付けてください。
- 何も話していない、または声が小さいと「聞き取れませんでした」と出ます。マイクが正しく選ばれているか、設定で確かめてください。

</details>

<details>
<summary>話し始めの言葉が抜ける</summary>

パネルに「聞き取り中…」と出てから話してください（マイクによっては、準備に 0.5 秒ほどかかります）。それでも抜けるときは、設定の「マイクを開いたままにする」をオンにしてください。

</details>

<details>
<summary>英語や専門用語がカタカナになる / よく間違える</summary>

設定の「置換辞書」に、間違え方と正しい書き方を登録してください。例えば「クローダオコード」→「Claude Code」と登録すると、次から自動で直ります。

</details>

## アンインストール

1. 「設定」→「アプリ」→「インストールされているアプリ」で kotoba-desktop の「…」→「アンインストール」を選びます（起動中なら自動で終了します）。
2. 設定とモデルは残るので、要らなければ次のフォルダも削除します。
   - 設定とログ: `%APPDATA%\kotoba-desktop`
   - 音声認識のモデル: `%USERPROFILE%\.cache\huggingface\hub` の中の `models--mobiuslabsgmbh--faster-whisper-large-v3-turbo`（kotoba-whisper に切り替えていた場合は `models--kotoba-tech--kotoba-whisper-v2.0-faster` も）

## プライバシー

- 音声認識はすべてパソコンの中で行います。音声も、認識した文字も、外部に送りません。
- 録音した音声と認識した文字は、ファイルに保存しません（直近 10 件の履歴は、アプリを終了すると消えます）。ログにも、文字の中身は書きません。
- インターネットを使うのは、モデルがまだ無いときのダウンロードだけです。
