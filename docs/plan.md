## 進め方

- 作業が終わったらチェックボックスを `[x]` にし、下の「現在地」と各フェーズの状態を更新する。コミットにはタスク ID（例: `P1-07`）を書く。
- 計測値や判断の根拠は、該当タスクの下に 1 行で残す（例: `→ 中央値 0.52 秒（10 回）`）。
- 設計を変えたときは設計書を直し、「決定事項」に日付と理由を 1 行で残す。
- 関門（G0 / G1）に合格するまで次のフェーズには進まない。

## Phase 1: MVP

機能要件 F1〜F6 を作る。Win32 の呼び出しは `win32/` に閉じ込め、それ以外は GPU なしで単体テストできるようにする。

### 土台

- [ ] **P1-01** 設定（`config.py`）: pydantic のスキーマ、`%APPDATA%\kotoba-desktop\config.toml` の読み込み、無ければ既定値で作成、誤りはどの項目かを返す
- [ ] **P1-02** Win32 ラッパー（`win32/`）: `input.py`（SendInput）、`clipboard.py`（退避・復元・更新番号・履歴除外形式）、`ime.py`、`window.py`（前面プロセス名・クラス名・昇格の判定）
- [ ] **P1-03** 起動（`__main__.py`）: 名前付きミューテックスで二重起動を防ぐ、cuBLAS の DLL を登録、`HF_HUB_OFFLINE=1`

### 録音から入力まで

- [ ] **P1-04** ホットキー（`hotkey.py`、F2）: 専用スレッドで RegisterHotKey（`MOD_NOREPEAT`）、既定は Ctrl+H、登録に失敗したら通知
- [ ] **P1-05** 録音（`audio.py`、F2）: WASAPI 共有モードで開き、soxr で 16 kHz モノラル float32 に変換、デバイスは設定で指定
- [ ] **P1-06** VAD: Silero VAD で前後の無音を切り、0.3 秒未満の発話は認識しない
- [ ] **P1-07** 認識（`asr.py`、F3）: `transcribe(audio) -> str` のインターフェースと faster-whisper 実装、起動時の読み込みとウォームアップ、`no_speech_prob` の高い区間を捨てる
- [ ] **P1-08** テキスト後処理（`textproc.py`、F4）: 禁止フレーズ、改行除去、全角英数字の半角化、句読点 `keep` / `strip`
- [ ] **P1-09** プロファイル（`inject/profiles.py`）: 前面ウィンドウから貼り付けキーを決める（Windows Terminal / コンソールは Shift+Insert、それ以外は Ctrl+V）
- [ ] **P1-10** 貼り付け入力（`inject/paste.py`、F3）: 設計書第 8 章の手順 1〜9。修飾キーが離れるのを待つ、管理者ウィンドウなら通知のみ、クリップボードの退避と復元
- [ ] **P1-11** Injector スレッド: 先入れ先出しのキューから 1 件ずつ入力する
- [ ] **P1-12** Controller（`controller.py`）: 待機 → 録音中 → 認識中 → 入力中 の状態遷移、認識中・入力中の押下は無視
- [ ] **P1-13** 履歴（F6）: 直近 10 件を保持し、選ぶと再入力。ディスクには保存しない

### UI

- [ ] **P1-14** トレイ（`ui/tray.py`、F1）: 履歴、マイク選択、設定を開く、再読み込み、ウィジェットを常に表示、終了
- [ ] **P1-15** ウィジェット（`ui/widget.py` + `Widget.qml`、F5）: 待機 / 録音中 / 認識中 / 入力完了 / エラーの表示、フォーカスを奪わない、ドラッグと位置の保存、表示タイミング
- [ ] **P1-16** 通知: モデル読み込み失敗、ホットキー登録失敗、管理者ウィンドウへの入力不可、設定の誤り

### 仕上げ

- [ ] **P1-18** 常駐用インストール（F1）: `uv tool install --editable .` とスタートアップフォルダのショートカット。手順を README に書く
